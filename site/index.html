      What is inside a bundle?

      A set of instructions and skill files for one practice area, plus a README-FIRST.md. Together they set up your AI project as a structured drafting and workflow aid.

      Do I need any technical setup?

      No. Download the ZIP, unzip it, and upload the files into a project or notebook on your AI platform. The files inside are plain text Markdown.

      The ZIP downloaded but will not open.

      Use your operating system's built-in extractor: on Windows, right-click the file and choose Extract All; on macOS, double-click it. Then open README-FIRST.md for upload steps.

      Which platform should I pick?

      Pick whichever AI tool you already use. Bundles are available for Claude Projects, ChatGPT Projects, and Gemini Notebooks (NotebookLM). The skills are the same; only the file layout differs.

      Is this legal advice?

      No. These bundles are workflow aids that support drafting and issue spotting. Every output is a starting point for attorney review, not legal advice.

      Is this affiliated with Anthropic, OpenAI, or Google?

      No. This is an independent open-source project. It is not affiliated with Anthropic, OpenAI, Google, or Claude for Legal.
