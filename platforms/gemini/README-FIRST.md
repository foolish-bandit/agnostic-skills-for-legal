# README-FIRST (Gemini Notebooks)

Welcome to your **Agnostic Skills for Legal** bundle for Gemini Notebooks (NotebookLM).

## What is this?
This is a pre-packaged set of legal AI instructions and skills for the **{{practice_area}}** practice area, optimized for use as sources in **Google NotebookLM**.

## How to Install
1.  **Create a Notebook:** Go to [notebooklm.google.com](https://notebooklm.google.com) and create a new notebook (e.g., "{{practice_area}} Workflows").
2.  **Upload Sources:** Upload **all** Markdown files in this ZIP file as sources for your notebook — `NOTEBOOK_INSTRUCTIONS.md` and every file in the `knowledge-base/` folder (the separate skill and template files).
3.  **Start Chatting:** Once the sources are uploaded, Gemini will have access to all your instructions and skills.

## Starter Message
After you have uploaded the files, copy and paste this message into the notebook chat to get started:

> "Use the uploaded Agnostic Skills for Legal materials for this practice area. Start by interviewing me about my role, jurisdiction, organization, preferred risk tolerance, and the type of legal work I want help with. Then create a short operating playbook for how you will assist me in this project."

## Important Notes
- **Attorney Review Required:** This bundle is a drafting and workflow aid. It is not legal advice. All AI-generated work product MUST be reviewed and verified by a qualified attorney.
- **Source Usage:** Gemini (NotebookLM) treats these files as ground-truth sources for its answers.
