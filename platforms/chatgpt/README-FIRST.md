# README-FIRST (ChatGPT Projects)

Welcome to your **Agnostic Skills for Legal** bundle for ChatGPT Projects.

## What is this?
This is a pre-packaged set of legal AI instructions and skills for the **{{practice_area}}** practice area, optimized for use in a **ChatGPT Project**.

## How to Install
1.  **Create a Project:** In ChatGPT, click on your name/profile and go to **"My plan" -> "Projects"** (or use the Projects sidebar) and create a new project (e.g., "{{practice_area}} Workflows").
2.  **Add Instructions:** Open **`PROJECT_INSTRUCTIONS.md`** in this ZIP file. Copy all the text inside. Paste it into the **"Project Instructions"** section of your ChatGPT Project.
3.  **Upload Files:** Upload the other Markdown files in this ZIP (like `{{manifest_id}}-skills.md` and any templates) to the Project's file storage.
4.  **Start Your First Chat:** Open a new chat in this Project.

## Starter Message
After you have uploaded the files, copy and paste this message into your first chat to get started:

> "Use the uploaded Agnostic Skills for Legal materials for this practice area. Start by interviewing me about my role, jurisdiction, organization, preferred risk tolerance, and the type of legal work I want help with. Then create a short operating playbook for how you will assist me in this project."

## Important Notes
- **Attorney Review Required:** This bundle is a drafting and workflow aid. It is not legal advice. All AI-generated work product MUST be reviewed and verified by a qualified attorney.
- **Trigger Phrases:** Use the trigger phrases defined in your instructions to guide ChatGPT's behavior.
