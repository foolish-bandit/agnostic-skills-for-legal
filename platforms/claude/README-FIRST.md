# README-FIRST (Claude Projects)

Welcome to your **Agnostic Skills for Legal** bundle for Claude Projects.

## What is this?
This is a pre-packaged set of legal AI instructions and skills for the **{{practice_area}}** practice area, optimized for use in a **Claude Project**.

## How to Install
1.  **Create a Project:** Log in to Claude.ai and click "Projects" in the sidebar. Create a new Project (e.g., "{{practice_area}} Workflows").
2.  **Add Instructions:** Open `instructions.md` in this ZIP file. Copy all the text inside. Paste it into the **"Custom Instructions"** section of your Claude Project.
3.  **Upload Knowledge:** Click "Add Content" or "Upload Files" in your Claude Project. Upload all files found in the **`knowledge-base/`** folder of this ZIP.
4.  **Start Your First Chat:** Open a new chat in this Project.

## Starter Message
After you have uploaded the files, copy and paste this message into your first chat to get started:

> "Use the uploaded Agnostic Skills for Legal materials for this practice area. Start by interviewing me about my role, jurisdiction, organization, preferred risk tolerance, and the type of legal work I want help with. Then create a short operating playbook for how you will assist me in this project."

## Important Notes
- **Attorney Review Required:** This bundle is a drafting and workflow aid. It is not legal advice. All AI-generated work product MUST be reviewed and verified by a qualified attorney.
- **Trigger Phrases:** Look at the `instructions.md` file to see "trigger phrases" (like "Review this contract") that activate specific workflows.
