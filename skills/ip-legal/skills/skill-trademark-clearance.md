# Skill: Trademark Clearance Intake & Triage

## When to use this skill
Use this to document the facts for a new trademark search and identify immediate "red flag" conflicts.

## Trigger phrases
- "Clear this trademark"
- "Trademark availability check"
- "Is this brand name available?"

## Required user inputs
- Proposed mark (text and/or image description).
- Description of goods and services.
- Geographic scope (e.g., US, EU).

## Workflow
1. **Mark Description:** Classify the mark (Sanciful, Arbitrary, Suggestive, Descriptive, Generic).
2. **Class Identification:** Determine the relevant International Classes (e.g., Class 9 for software, Class 42 for SaaS).
3. **Risk Analysis:** Identify potential "Likelihood of Confusion" issues based on similar marks in similar classes.
4. **Descriptiveness Check:** Flag if the mark is too descriptive of the goods/services.

## Output format: Clearance Triage Report
- **Mark Strength:** [Category] - Analysis of registrability.
- **Recommended Classes:** List of International Classes.
- **Red Flags:** Immediate conflicts found in provided data or preliminary search.
- **Search Strategy:** Recommended terms for a professional comprehensive search.

## Example starter prompt
"Help me clear the trademark 'CloudGuard' for a new network security software. We plan to launch in the US and Canada."
