# Organizational AI Policy Template

## 1. Purpose
- State the organization's goals for using AI.

## 2. Permitted Uses
- Define approved AI tools and use cases.

## 3. Prohibited Uses
- List forbidden activities (e.g., entering confidential client data into public models).

## 4. Oversight & Accountability
- Identify the team/person responsible for AI governance.

## 5. Security & Privacy
- Data protection requirements for AI systems.
