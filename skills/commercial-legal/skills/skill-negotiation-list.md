# Skill: Negotiation Issues List

## When to use this skill
Use this to prepare for a negotiation by summarizing key sticking points and suggesting trade-offs.

## Trigger phrases
- "Create a negotiation list"
- "Sticking points summary"
- "Prep me for a negotiation"

## Required user inputs
- Redlined contract or two versions of a contract.
- Organization's "must-haves" vs. "nice-to-haves."

## Workflow
1. **Identify Sticking Points:** Find clauses where parties disagree (e.g., Liability caps, Indemnity triggers).
2. **Assign Priority:** Rank issues based on business impact.
3. **Draft Positions:** Create a "Current Position," "Opposing Position," and "Proposed Compromise" for each.

## Output format: Negotiation Position Chart
| Issue | Our Position | Their Position | Proposed Trade-off / Compromise |
| :--- | :--- | :--- | :--- |
| [e.g. Liability] | [1x Fees] | [Unlimited] | [2x Fees or Specific Dollar Cap] |

## Example starter prompt
"Based on the attached redlines, create a negotiation issues list for our call tomorrow. We can be flexible on Governing Law but must have a 1x cap on liability."
