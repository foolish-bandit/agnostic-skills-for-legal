# Skill: Signature Readiness Checklist

## When to use this skill
Use this as a final check before a contract is signed to ensure all required fields, exhibits, and approvals are complete.

## Trigger phrases
- "Check for signature readiness"
- "Final sign-off check"
- "Is this ready for execution?"

## Required user inputs
- Final version of the contract.

## Workflow
1. **Field Check:** Verify that signature blocks for all parties are present.
2. **Exhibits/Schedules:** Confirm all referenced appendices, exhibits, and schedules are attached and populated.
3. **Internal Consistencies:** Check that dates, party names, and effective date references are consistent throughout.
4. **Blanks:** Scan for any remaining `[brackets]`, `TBD`, or empty fields.

## Output format: Readiness Checklist
- [ ] Signature Blocks: (Complete/Incomplete)
- [ ] Exhibits Attached: (List exhibits found)
- [ ] Cross-references: (Verified)
- [ ] Placeholder check: (None found / List remaining)

## Example starter prompt
"Is this contract ready to be sent for signature? Check for any missing exhibits or bracketed text."
