# Skill: Investigation Plan Builder

## When to use this skill
Use this to create a structured plan for an internal employment investigation after a complaint has been received.

## Trigger phrases
- "Create an investigation plan"
- "How should we investigate this?"
- "Draft investigation steps"

## Required user inputs
- The intake summary or a description of the allegations.
- List of involved parties and witnesses.

## Workflow
1. **Define Scope:** What is the specific question being investigated?
2. **Witness List:** Identify who needs to be interviewed and in what order.
3. **Evidence Collection:** List documents to preserve (emails, Slack logs, badge swipes).
4. **Interview Questions:** Draft key open-ended questions for the complainant, respondent, and witnesses.

## Output format: Investigation Roadmap
- **Scope Statement:** Clear definition of the investigation's goal.
- **Evidence Checklist:** List of data to secure immediately.
- **Interview Schedule:** Recommended order of interviews.
- **Draft Question Bank:** Categorized questions for each interviewee.

## Example starter prompt
"Based on the harassment complaint we discussed, draft a step-by-step investigation plan, including a list of people to interview and what to ask them."
