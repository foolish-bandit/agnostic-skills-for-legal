# Skill: Discovery Request Drafting

## When to use this skill
Use this to draft initial Requests for Production (RFPs) or Interrogatories.

## Trigger phrases
- "Draft discovery requests"
- "Create RFPs"
- "Draft interrogatories"

## Required user inputs
- Complaint or Answer (to identify relevant issues).
- Target of the discovery (Plaintiff/Defendant).

## Workflow
1. **Issue Mapping:** Identify the key factual disputes in the pleadings.
2. **Category Definition:** Group requests by category (e.g., Financials, Communications, Policies).
3. **Drafting:** Write specific, targeted requests that avoid "overly broad" objections.
4. **Definitions/Instructions:** Include standard discovery boilerplate.

## Output format: Discovery Chart
- **RFPs:** List of 10-15 targeted requests for documents.
- **Interrogatories:** List of 5-10 targeted questions.
- **Rationale:** Explanation of why each request is relevant to the claims.

## Example starter prompt
"Draft 10 targeted Requests for Production for the Defendant based on the attached Complaint. Focus on emails related to the product defect."
