# Skill: Board Consent / Written Consent Drafter

## When to use this skill
Use this to draft an outline of a board or stockholder written consent (action by written consent in lieu of meeting) for a specified corporate action, based on uploaded charter documents and prior consents.

## Trigger phrases
- "Draft a board written consent"
- "Outline a stockholder consent"
- "Prepare a unanimous written consent"

## Required user inputs
- Uploaded charter, bylaws, and/or stockholders' agreement.
- The corporate action(s) to be approved (e.g., issuance, option grant, officer appointment, transaction approval).
- Approving body (Board, Stockholders, both) and any required vote threshold.
- Uploaded prior consents to use as form/style references (optional).

## Workflow
1. **Authority Check:** Identify, from charter docs, the body required to approve each action and the vote threshold. Cite the section.
2. **Resolution Outline:** Draft a "RESOLVED" outline for each action, including incorporated references to exhibits (e.g., form of grant notice, transaction documents).
3. **Recitals:** Draft factual recitals that cite the underlying documents (e.g., "the Company desires to enter into that certain Agreement attached hereto as Exhibit A").
4. **Signature Block:** Identify the signatories required (directors / stockholders) and threshold.

## Output format
Provide a clearly labeled draft outline containing:
1. **Header** (entity, "Action by Written Consent of the [Board/Stockholders] in Lieu of Meeting")
2. **Recitals** (WHEREAS clauses with source citations)
3. **Resolutions** (RESOLVED, FURTHER RESOLVED ...)
4. **Authority & Effective Date**
5. **Signatures** (placeholders with required threshold)

Follow with:
- **Authority Citations Table** (Action | Approving Body | Threshold | Source §)
- **Open Items** (missing exhibits, ambiguous quorum/threshold rules)

## Guardrails
- This is a drafting outline, not a final consent. Mark clearly as DRAFT.
- Do not state that the consent is effective; effectiveness depends on actual execution and threshold satisfaction.
- If the charter docs are silent or conflicting on threshold, flag for attorney review.

## Example starter prompt
"Outline a unanimous board written consent approving (1) an option grant to a new VP Eng and (2) entry into the attached SaaS reseller agreement. Use the uploaded bylaws."
